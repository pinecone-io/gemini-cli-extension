# Contributing to the Pinecone Gemini CLI Extension

Thank you for your interest in improving the Pinecone Gemini CLI extension! We value your feedback and contributions.

## Reporting Issues

If you encounter a bug or have a feature request, please file an issue in our GitHub repository. To help us resolve it quickly, please include:

1. **Clear Title:** A brief, descriptive title for the issue.
2. **Detailed Description:** What happened, and what did you expect to happen?
3. **Reproduction Steps:** List the steps or commands you ran that led to the issue.
4. **Environment Info:**
   - Your OS (e.g., macOS, Linux, Windows)
   - Your Gemini CLI version
   - Whether you are using the Pinecone CLI (`pc`) or the Pinecone MCP server
5. **Screenshots/Logs:** If applicable, provide screenshots of the error or the output from your terminal.

### Filing a Bug
Before filing, please check the existing issues to see if the bug has already been reported. If it has, you can add a comment to that issue with your additional information.

### Suggesting Enhancements
We're always looking to improve! If you have an idea for a new feature or a better way to do something, please open an issue and label it as a `feature request`.

## Submitting Pull Requests

If you'd like to contribute code:

1. **Fork the Repository:** Create your own fork of the project.
2. **Create a Branch:** Give your branch a descriptive name (e.g., `fix/api-key-error` or `feat/new-skill`).
3. **Make Your Changes:** Follow the project's coding style and conventions.
4. **Add Tests:** If you're adding a new feature or fixing a bug, please include relevant tests.
5. **Submit a PR:** Provide a clear description of your changes and why they are needed.

## Style & Standards

- **Agent Skills:** Ensure all `SKILL.md` files follow the standard format with a name and description in the frontmatter.
- **Documentation:** Keep `GEMINI.md` and `README.md` updated with any changes to skills or tools.
- **Python Scripts:** If adding scripts to skills, use `uv` inline dependencies where possible to simplify execution for users.
